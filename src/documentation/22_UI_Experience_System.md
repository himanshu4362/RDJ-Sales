# 22_UI_Experience_System.md

## 1. The Core Aesthetic
* **Vibe:** Powerful, Reliable, Professional, Industrial.
* **Avoid:** Minimalist luxury, playful animations, or cramped e-commerce grids.

## 2. Visual Laws
* **Hero Sections:** Every major customer-facing page must have one visual anchor (typography, photography, or illustration). A page never starts immediately with a card.
* **Lists & Cards:** Cards must breathe. Enforce minimum spacing and strong typography hierarchy. No cramped grids.
* **Empty States:** Never use generic UI icons. Always use intentional, branded artwork from the Asset Backlog.
* **Primary Actions:** Every page has exactly ONE primary CTA. Never force the user to choose between three competing buttons.
* **Rhythm:** The page must naturally flow: `Hero` → `Context` → `Main Content` → `Trust` → `Action`.

## 3. Mandatory Assets
* **Brand Logo:** P0 (Navigation, Splash, Auth).
* **Product Images:** P0 (Every product page).
* **Hero Banners:** P1 (Customer landing pages).
* **Empty State Artwork:** P1 (Every module).
* **Success Illustrations:** P1 (Every important submission).

## 4. Surface Hierarchy
Not every piece of information deserves a card. Use visual hierarchy in this strict order:
1. Whitespace
2. Typography
3. Background contrast
4. Borders
5. Shadows
*Rule:* Borders should separate information—not create information.

## 5. Photography
Images should demonstrate capability. We are selling professional audio expertise, not consulting services.
* **Preferred:** Workshop benches, real products, installation sites, technicians, custom cabinets, stage setups.
* **Avoid:** Generic office people, handshakes, stock business meetings, smiling headset operators.
